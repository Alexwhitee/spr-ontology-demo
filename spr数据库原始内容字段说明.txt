SPR数据库原始内容、字段说明
数据规模：666 条记录，16 个字段
[图片]
这份文件字段包含 ID、线体、设备、车身、程序、曲线数据和系统时间。
主键 / 业务 ID
包括：
- id：数据记录主键 ID
- biz_id：业务 ID / 业务唯一编号
这两个字段都是唯一的：
工艺 / 铆点 / 车身 / 设备信息
包括：
- prog_no：程序号
- rivet_id：铆点编号 / 铆钉点位编号
- carbody_id：车身 ID / 车身编号
- line_name：产线 / 线体 / 工位区域名称
- device_name：设备名称
其中：
- prog_no：程序号，有 49 种
- rivet_id：铆点编号 / 铆钉点位编号，有 44 种
- carbody_id：车身 ID / 车身编号，有 56 种，649 条非空
- line_name：产线 / 线体 / 工位区域名称，有 9 类，包括 RC、UR、UB、HD、AFO、AFI、MC、AHD、FI
- device_name：设备名称，有 53 种，例如 RC050R02、UR060R03、HD025R04 等

---
曲线数据
包括：
- original_data：原始曲线数据
- calculate_data：计算后曲线数据 / 处理后曲线数据
特点：
- original_data：原始曲线数据，已经是浮点数序列
- calculate_data：计算后曲线数据 / 处理后曲线数据，通常保留到 3 位小数
- original_data：原始曲线数据 和 calculate_data：计算后曲线数据 / 处理后曲线数据，这两个字段每条记录都不一样

---
误差 / 预测或判定字段
包括：
- error_rate：误差率 / 异常率
- pre：预测结果 / 预判类别
其中：
error_rate：误差率 / 异常率 分布：
- 0.000：599 条
- 0.010：62 条
- 其他少量异常值，包括 0.120、0.040、88.040、99.990、95.700
pre：预测结果 / 预判类别 分布：
- 1.000：548 条
- 3.000：115 条
- 0.000：3 条

---
系统时间与删除标识
包括：
- consumer_time：消费时间 / 数据消费时间
- origin_time：原始数据时间 / 设备采集时间
- is_deleted：是否删除 / 删除标记
- create_time：创建时间
- update_time：更新时间
